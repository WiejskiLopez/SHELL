Struktura tej aplikacja i modulow ma byc taka ze
Kazda instancja app uruchamia sie na jednym node.
Na jednym wezle jest to wezel funkcyjny decyzyjny zajmuje sie jednym zebranym temetem
w postaci agenta lub deterministycznego skrypt.
I kazda app jest powiazana tylko z takim jednym nodem.
Kazda app moze byc:
1)app deterministyczna tzw worker,
2)app oparta na llm tzw agent

Worker pelnic moze funkcje 
a) tools - zwykly skrypt narzedziowy
b) tasker - graph ktory uruchamia kolejne app cyklicznie
c) router  - blok decyzyjny przesylania danych miedzy nodami

Agent moze pelnic funkcje
a) tools - logiczne narzedzie wykorzystujace ai

Ogolnie nazywamy aplikacje Runnerem, bez wzgledu na to kim jest i co robi.
Czyli startujac aplikacje przygotowujemy ja do startu, parametrami i srodowiskiem.
Konfigurujemy wszystko co Runner potrzebuje i na koncu mowimy Runnerowi -> Run
I ma sie wykonywac zasadnicza czesc pracy aplikacji.
Czyli runner odpowiada za 
a) uruchamianie agent
b) uruchamianie tool konkretnego (ktory z wejscia robi wyjscie lub cos robi w zalaczonych dir ktore sa Workspace)
c) uruchamianie routingu czyli przesylanie tematow z dowolnego node na dowolny node
d) uruchamianie task - jest orkiestratorem i uruchamia w kolejnych app zadania typu a), b), c)



runner typu: tasker -> this(graph) -> others(1 - n nodes[role])
runner typu: agent -> this(llm) -> this(node[role])
runner typu: worker -> this(tool)-> this(node[role])
runner typu: router -> this(tool,llm)-> this(node[role])
